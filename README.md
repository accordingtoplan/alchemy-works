# Alchemy Works

Website for Alchemy Works, in progress. Live preview at https://new.alchemyworks.us. Not yet the live alchemyworks.us.

White version only. Built with `python3 build.py && python3 generate.py` in the project folder: homepage from `prototype-v2/index.html`, detail pages (shop, products, brands, stores, about, journal) from `data-focus-products.json`.

Product, campaign and lifestyle images are placeholders from the brands Alchemy Works carries and from reference sources, to be replaced before launch. Product data, prices and in-store stock are sample data until the store's Shopify and POS are connected.
